
# V2 - Parallel Load Counter

## Overview
Enhanced the V1 Up/Down Counter by adding parallel load functionality using Verilog HDL.

## Features
- Synchronous active-low reset.
- Enable-controlled counting.
- Up-counting and down-counting.
- Parallel loading of input data.
- Counter rollover and underflow.

## Files
- counterv2.sv - Updated RTL design.
- testbenchv2.sv - Simulation testbench.
- waveformv2.png - EPWave simulation screenshot.

## Tools Used
- Verilog HDL
- Icarus Verilog
- EDA Playground
- EPWave
- GitHub

## Verification
Verified reset, parallel load, up-counting, down-counting and hold operations through simulation.

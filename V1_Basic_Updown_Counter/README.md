
# V1 - Basic Up/Down Counter

## Overview
Designed a parameterized 4-bit Up/Down Counter using Verilog HDL.

## Features
- Synchronous active-low reset.
- Enable-controlled counting.
- Up-counting and down-counting.
- 4-bit rollover and underflow.

## Files
- counterv1.sv - RTL design.
- testbenchv1.sv - Simulation testbench.
- v1_waveform.png - EPWave simulation screenshot.

## Tools Used
- Verilog HDL
- Icarus Verilog
- EDA Playground
- EPWave

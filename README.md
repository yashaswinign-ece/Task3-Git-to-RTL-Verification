# Task 3: Git-to-RTL Verification Flow

## Project Overview
Designed and simulated a parameterized 4-bit Up/Down Counter using Verilog HDL.

## Features
- Synchronous active-low reset.
- Enable-controlled counting.
- Up-counting and down-counting.
- Parameterized counter width.
- Counter rollover and underflow.

## Files
- counter.sv - RTL design.
- testbench.sv - Simulation testbench.
- Screenshot 2026-11-09 221023.png - EPWave waveform verification.

## Tools Used
- Verilog HDL
- EDA Playground
- Icarus Verilog
- EPWave
- GitHub

## Verification
Verified reset, enable, up-counting and down-counting using simulation waveforms.

## Git Version Control
RTL changes will be tracked through meaningful Git commits. Each modification will be verified through simulation.
